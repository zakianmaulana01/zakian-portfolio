# Ikon teknologi

SVG dari [Simple Icons](https://github.com/simple-icons/simple-icons), diunduh dari folder `icons` pada 12 September 2026. Simple Icons didistribusikan dengan CC0-1.0; hak merek masing-masing tetap milik pemiliknya. Ikon digunakan untuk mengidentifikasi teknologi, dalam warna monokrom.

REST API, SQL Server, dan teknologi lain tanpa SVG menggunakan ikon generik Phosphor yang sudah tersedia di proyek.
